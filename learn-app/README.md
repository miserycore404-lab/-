# Line by Line

A study app for learning things by heart: texts line by line, plus formulas,
definitions, theorems, rules and dates sorted by subject. Works offline and
installs on your phone's home screen.

## Features
- **Texts**: photo or paste → split into steps → Look & copy → Fade → From memory. Other methods: First letters, Puzzle, Say it (microphone). Chain mode links steps together.
- **Cards**: formulas (with a symbol keyboard and real superscripts: type `a^2`, `x_1`, `x^{n-1}`), definitions, theorems, rules, facts/dates.
- **Practice**: Flashcards (Again / Hard / Good / Easy), Type it (formulas compared symbol by symbol), Quiz (multiple choice).
- **Spaced review**: everything comes back after 1, 3, 7, 14, 30, 60 days.
- **Subjects**, search, daily goal, streak, 16-week activity map.
- **Starter packs**: algebra, geometry & trig, derivatives, physics, chemistry, cell biology, key dates, Romanian spelling.
- **Languages**: Romanian is the default for new items (photo reading, voice, mic). The app's buttons and menus are in English.
- **Backup**: save and restore everything as a file.

## Install on your phone
The app has to be served over HTTPS (e.g. GitHub Pages, Netlify, Cloudflare Pages).
Upload this folder, open `index.html` on your phone, then:
- **Android (Chrome)**: menu ⋮ → *Install app* / *Add to Home screen*.
- **iPhone (Safari)**: Share → *Add to Home Screen*.

## Develop
Edit `app.html`, then run `./build.sh` to regenerate `index.html`.
